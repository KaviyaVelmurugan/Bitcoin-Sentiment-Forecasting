# Public release boundaries

Project software is MIT licensed. CryptoPulse's original MIT notice is retained. Dataset and publisher rights remain separate.

The public demo uses fictional data generated locally. It loads no API key or private provider text. Historical findings in the report concern the completed experiment; demo charts do not reproduce those results.

Ignore `work/`, environments, keys, private news, databases, trained models and temporary files. Legacy local guides are excluded from the release. Do not replace the curated release with a ZIP of the entire working folder.

`bitcoin-sentiment-forecasting-public.zip` is the curated source package. Before uploading, check that the repository is named as intended and set its visibility to public. Images can be added later. No repository was pushed during this preparation.

The demo runs from a clean checkout. Exact historical reproduction still requires the original licensed archives and saved manifests. Future model changes need new evaluation data because the final holdout is now inspected.
